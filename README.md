## 日本IIJ VPS分两种：卖路由的和卖IP归属的

一类卖的是**路由**。流量走 IIJ 骨干网，从中国大陆、香港、东南亚连过去路径干净、延迟低（有测评给出东京 IIJ 线路国内主要城市约 70ms 的成绩），但 IP 本身仍然注册在机房 ASN 下，平台一查就是"hosting provider"。
